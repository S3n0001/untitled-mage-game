# Aesthetic Direction

Use this reference when craft-contextual-ui handles greenfield work or an explicit aesthetic-direction brief: no established product system constrains the design, and templated output is the main risk.

## Recognize default output

Generated design currently clusters around a few recognizable looks: a warm cream page with a high-contrast serif display and a terracotta accent; a near-black page with a single acid-bright accent; a dense broadsheet layout of hairline rules and zero border-radius. Each is legitimate when the brief or the product's world genuinely calls for it. Treat them as defaults to justify, not choices: when a candidate direction matches one, require evidence from the brief before keeping it, and spend every free axis on choices specific to the subject. Follow the brief's explicit visual direction exactly, including when it names a common look.

Apply the same test to structural devices. Numbering, eyebrows, dividers, and labels must encode something true about the content; number a sequence only when order carries information the reader needs.

## Plan the direction before building

Write a compact direction plan first:

- Palette: four to six named values with roles.
- Type: a characterful display face used with restraint, a complementary body face, and a utility face only when captions or data need one; a deliberate scale with intentional weights and spacing.
- Layout: the concept in one or two sentences, with a rough wireframe when comparing candidates.
- Signature: the single element this surface will be remembered by, rooted in the subject's own world — its materials, instruments, artifacts, and vernacular.

Then audit the plan: for any part you would also produce for a generically similar brief, revise it and record what changed and why. Derive every color and type decision in the implementation from the revised plan.

## Spend boldness once

Let the signature element carry the risk and keep everything around it quiet and disciplined. After the first complete pass, remove one decorative element and confirm nothing is lost. Taking no risk is itself a risk: a direction with no memorable choice fails an aesthetic brief. Hold the main skill's quality floor without announcing it — responsive recomposition, visible focus, reduced-motion behavior.

## Write the words as direction

Copy is design material: placeholder text can make a distinctive design read templated. Beyond the main skill's content rules — specific labels, stable action names, useful empty states, errors that explain recovery — apply:

- Name things by what the person controls and recognizes, never by how the system is built.
- Say exactly what a control does, in active voice, and keep an action's name stable through the flow it starts and the confirmation it produces.
- Match register to the brand and audience: plain verbs, sentence case, no filler.
- Give each element one job: a label labels, an example demonstrates, nothing quietly does double duty.
